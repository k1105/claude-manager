# 部門完了時のエスカレーション（秘書ゆりか宛）

各部門（さくら / タナカ / レイ）は、割り当てられた仕事が一段落したら、自走で次の指示を待たずに **秘書ゆりか（tmux pane `claude:0.0`）にエスカレーション**する。ユーザーが各部門を直接見ていないとき、秘書経由で次の判断が回るための導線。

## 送信手順

完了したら以下を Bash で実行する：

```sh
tmux send-keys -t claude:0.0 -l "<部門名>から完了報告: <要点1行> / 詳細は <ファイルパス>"
sleep 0.3
tmux send-keys -t claude:0.0 Enter
sleep 0.3
tmux send-keys -t claude:0.0 Enter
```

ENTER が貼り付けバッファの改行に取られるのを避けるため、テキストと Enter を分離する。

## 報告フォーマット

- 1 行目（要点）: 「<部門名>から完了報告: <何が終わったか>」
- 詳細リンク: 該当 status.md / PR / コミットへのパス
- 次の手の提案がある場合は 1 行添える（任意）

## 例

```
さくらから完了報告: Apple HIG 刷新 1st pass 完了（ボタン/フォント/SF Symbols差し替え） / 詳細は projects/avatar-quality/status.md / 次は連絡先画面の余白調整に入れる
```

## 自分から送らないケース

- ユーザーが同じセッションで対話中（直接やりとり優先）
- まだ作業が継続中で、ユーザーの判断を仰ぐ必要がない確認だけ

## 秘書側の動き

- ゆりかは受け取った報告を踏まえ、ユーザーに進捗をまとめる
- 次タスクを判断できるなら自分の責任で部門へ再投入
- ユーザー判断が要る論点は集約してユーザーに上げる
